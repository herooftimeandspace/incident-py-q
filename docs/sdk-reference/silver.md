# `silver` Namespace

Sync client access: `client.silver`

Async client access: `client.silver` with `await` on async methods.

Silver routes are undocumented APIs observed in tenant HAR traffic. The SDK exposes them explicitly and separately because the Golden contract is always preferred when they exist.
