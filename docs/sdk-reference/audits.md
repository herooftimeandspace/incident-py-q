### `add_asset_to_audit_policy`

Provenance: Golden OpenAPI contract

Operation ID: `addAssetToAuditPolicy`

- Sync: `client.audits.add_asset_to_audit_policy(asset_audit_policy_id=..., asset_id=..., timeout=None)`
- Async: `await client.audits.add_asset_to_audit_policy(asset_audit_policy_id=..., asset_id=..., timeout=None)`
- Raw payload: `client.audits.add_asset_to_audit_policy.raw(asset_audit_policy_id=..., asset_id=..., timeout=None)`
- HTTP route: `GET /api/v1.0/audits/policies/{AssetAuditPolicyId}/add/asset/{AssetId}`
- Source controller: `IncidentIQ API`

Add asset to audit policy

Adds a specific asset to an audit policy's scope. This operation associates the asset with the policy, causing future audit schedules generated by the policy to include this asset. The asset will be subject to the policy's verification requirements, schedules, and alert rules. This endpoint is typically used when expanding an existing audit policy's coverage to include additional assets.

**Prerequisites:**
- Asset Audit Policy ID must be obtained from [GET /api/v1.0/audits/policies](#/Audits/getAssetAuditPolicies)
- Asset ID must be obtained from [POST /api/v1.0/assets](#/Assets/searchAssets)

**Workflow Example:**
1. List audit policies: [GET /api/v1.0/audits/policies](#/Audits/getAssetAuditPolicies)
2. Extract the target policy's `AssetAuditPolicyId` from `Items[].AssetAuditPolicyId`
3. Search for the asset to add: [POST /api/v1.0/assets](#/Assets/searchAssets)
4. Extract the asset's `AssetId` from `Items[].AssetId`
5. Add the asset to the policy using this endpoint

**Response:**
Returns a success message confirming the asset was added to the policy.

#### Parameters

| Python Arg | API Name | In | Required | Type | Schema / Model | Description |
| --- | --- | --- | --- | --- | --- | --- |
| `asset_audit_policy_id` | `AssetAuditPolicyId` | `path` | `yes` | `str` | `-` | The unique identifier of the asset audit policy |
| `asset_id` | `AssetId` | `path` | `yes` | `str` | `-` | The unique identifier of the asset to add to the policy |

#### Returns

- Typed call return: `ActionResponse`
- Raw payload return: `dict[str, Any] | list[Any] | None`
- Response model: `ActionResponse`

List assets in audit schedule instance

Retrieves all assets included in a specific audit policy schedule instance. Returns the complete list of assets that were scheduled for verification during this particular schedule period. This differs from the policy-level asset list because it represents the snapshot of assets at the time the schedule was generated, which may differ from the current policy scope if assets have been added/removed or policy targeting rules have changed. Each asset includes full details and the asset's compliance status for this schedule period.

**Prerequisites:**
- Asset Audit Policy Schedule ID must be obtained from [GET /api/v1.0/audits/policies/schedules/for-asset/{AssetId}](#/Audits/getAssetAuditPolicySchedulesForAsset) or policy schedule endpoints

**Workflow Example:**
1. Get schedules for an asset or policy to identify the target schedule
2. Extract the schedule's `AssetAuditPolicyScheduleId`
3. Get the list of assets in this schedule instance using this endpoint
4. Review which assets were included in this particular verification period

**Response Fields:**
